# lab2-openshift-app

Material de partida do **Laboratório Final 2 de Red Hat OpenShift** (curso 200DEV).

Conteúdo:

- `index.html`: página estática da aplicação "Biblioteca Comunitária", com o texto `versão 1`.
- `Dockerfile`: imagem baseada em `registry.access.redhat.com/ubi9/nginx-124`. A aplicação escuta na porta **8080**.

Use este repositório pelo fork indicado no guia do laboratório. Não é preciso alterar nada para o Bloco 8; a alteração para `versão 2` faz parte do Bloco 9.
